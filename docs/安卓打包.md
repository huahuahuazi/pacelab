# 安卓打包与安装

把网页版打成可以直接装到手机上的 apk。整个壳只有 280 行 Java，不做别的事：加载本地网页、接住文件选择、把导出文件落盘。

---

## 一、为什么是这个方案

| 方案 | 为什么没用 |
|---|---|
| Capacitor | 要多装 60+ 个 npm 包、一套 Gradle 插件链，还要 `npx cap sync` 同步。功能上这个 App 一个都用不上 |
| 纯 `file://` 加载网页 | WebView 里 `<script type="module">` 会被 CORS 直接拦死，**整个 App 白屏**。这是最容易踩的坑 |
| 微信小程序 | 要 AppID、备案、审核，且托管不了，跟"推到 GitHub 就能用"冲突 |

实际用的是 **WebView + WebViewAssetLoader**：把 `assets/www` 映射到
`https://appassets.androidplatform.net/assets/www/`，等于给本地资源套了一个 https 域名。
module、fetch、Worker、wasm 全部正常工作，且是安全上下文。

---

## 二、一次性环境准备

只需要三样，装完就不必再管：

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17 | AGP 8.x 硬性要求。8 或 11 不行 |
| Gradle | 8.7 | 也可以直接用 `android/gradlew`（已内置 wrapper） |
| Android SDK | platform-34 + build-tools 34.0.0 | 只需要这两个，不用装 Android Studio |

不想污染系统的话，全部解压到独立目录即可，构建时用环境变量指过去：

```bash
export JAVA_HOME=/d/android-toolchain/jdk-17.0.21+9
export ANDROID_HOME=/d/android-toolchain/sdk
export ANDROID_SDK_ROOT=$ANDROID_HOME
```

SDK 组件安装（一次性）：

```bash
sdkmanager --sdk_root=$ANDROID_HOME "platform-tools" "platforms;android-34" "build-tools;34.0.0"
```

Windows PowerShell 写法：

```powershell
$env:JAVA_HOME = "D:\android-toolchain\jdk-17.0.21+9"
$env:ANDROID_HOME = "D:\android-toolchain\sdk"
& "D:\android-toolchain\sdk\cmdline-tools\latest\bin\sdkmanager.bat" `
  --sdk_root="D:\android-toolchain\sdk" "platform-tools" "platforms;android-34" "build-tools;34.0.0"
```

## 三、构建

```bash
cd "D:/workbuddy工作区/跑步app"
node android/sync-web.mjs        # 网页资源 → android/app/src/main/assets/www
cd android
./gradlew assembleRelease
```

产物：`android/app/build/outputs/apk/release/app-release.apk`

**每次改完网页代码，都要重新跑 `sync-web.mjs` 再打包**——网页是同步进 assets 的副本，
不跑这一步打出来的还是旧页面。

调试版（带 WebView 远程调试）：

```bash
./gradlew assembleDebug
# 产物 android/app/build/outputs/apk/debug/app-debug.apk
# 手机连电脑后，Chrome 打开 chrome://inspect 就能调试页面
```

## 四、装到手机

1. 把 apk 传到手机（微信文件传输 / 数据线 / 网盘都行）
2. 点击安装，系统提示「未知来源应用」时选择允许
3. 首次打开会申请相册权限——**只在你要传跑步截图时才会用到**

卸载会一并清除数据。**换手机前先在「我的 → 导出备份」存一份 JSON。**

## 五、签名（想自己发版才需要）

仓库里没有密钥。没配密钥时构建会自动退回 debug 签名，照样能装能用，只是不能上应用商店。

自己生成一个：

```bash
cd android
$JAVA_HOME/bin/keytool -genkeypair -v \
  -keystore pacelab-release.keystore -alias pacelab \
  -keyalg RSA -keysize 2048 -validity 10950 \
  -storepass <你的密码> -keypass <你的密码> \
  -dname "CN=PaceLab, OU=Mobile, O=PaceLab, L=Shanghai, ST=Shanghai, C=CN"
```

在 `android/keystore.properties` 填写：

```properties
storeFile=pacelab-release.keystore
storePassword=你的密码
keyAlias=pacelab
keyPassword=你的密码
```

`*.keystore` 和 `keystore.properties` 都已在 `.gitignore` 里，不会被推到仓库。

**密钥丢了就再也无法给同一个应用发更新**，务必备份。

## 六、踩过的坑（按踩到的顺序）

| 现象 | 原因 | 处理 |
|---|---|---|
| 构建直接失败：`Your project path contains non-ASCII characters` | 项目在 `D:\workbuddy工作区\` 下，路径含中文，AGP 主动拒绝 | `gradle.properties` 加 `android.overridePathCheck=true` |
| 页面白屏，控制台报 CORS | 用 `file://` 加载，ES module 跨源 | 改 `WebViewAssetLoader` 映射成 https |
| 点「上传截图」没反应，也不报错 | 没实现 `WebChromeClient.onShowFileChooser` | MainActivity 里补上，走 `ACTION_GET_CONTENT` |
| 点「导出备份」没反应 | WebView 不支持 `<a download>` 的 blob 下载 | 加 `@JavascriptInterface` 原生落盘到「下载」目录 |
| 图片识别加载 3 秒后失败 | tesseract v5 要的是 `*-lstm.wasm.js` LSTM 专用内核，通用版文件名不对 | 内核文件换成 `tesseract-core-simd-lstm.*` |
| 识别结果只认出配速，距离时长全空 | 截图里 "10.02 km" 的单位被 OCR 吃掉；`50:12` 被误判成配速 | 加无单位数字兜底 + 用 120~900 秒区间卡配速合法性 |
| 系统字体调大后布局崩 | WebView 跟随系统字体缩放 | `settings.setTextZoom(100)` 锁死 |

## 七、改网页后要做什么

```bash
node android/sync-web.mjs    # 必须
cd android && ./gradlew assembleRelease
```

如果改了 `js/app.js` 里的界面逻辑，网页版和 App 版共用同一份代码，**一处改动两端同时生效**。
只有涉及原生能力的部分（导出落盘）需要判断 `window.AndroidBridge` 是否存在。
